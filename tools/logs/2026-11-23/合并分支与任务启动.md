# 合并分支与任务启动

2026-11-23

- 将 communication 和 safety 合入 main，保留安全区实验资料和本地新版客户端的安全区调试。物块消息仍只传 header 和 items。
- 客户端选择红蓝方后用 `bash tools/preview.sh start task red` 准备，蓝方填 blue。正式任务等待 STM32 的 `00, 1`，也可以用客户端按钮调用 `bash tools/preview.sh start-task`。
- 下发 `00` 保留，串口启动只发 `08, 0` 停车。启动请求需要串口打开、队伍已设定和新的检测帧。

WSL 下 7 个 ROS 2 包和 Windows Qt 客户端均已编译。使用伪串口验证初始停车、蓝方配置、角度反馈、拒绝 `00, 0`、STM32 启动和客户端调用的 ROS 服务。未联调实车。
