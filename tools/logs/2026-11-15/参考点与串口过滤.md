# 2026-11-15 · 预览参考点、串口过滤与滚动条

时间：13:24–13:50

## 改动

### 1. 预览上画参考点

- `desktop_server_node` 新增参数 `point.x0`、`point.y0`（默认 640、550），
  在缩放后的预览图上画绿色十字加小圆圈，位置按预览比例缩放；
- `robot.launch.py` 从 `robot.yaml` 读参考点：靠近测试用
  `approach_test_node.point`，其余用 `task_node.point`，再传给 HTTP 服务。

验证：派上 640×360 的预览图里，十字在 (320, 275)，对应原图 (640, 550)。

![参考点](参考点.jpg)

### 2. 没检测到目标不发命令

`approach_test_node.on_frame()` 里原来找不到目标会发 `06` 停车，现在直接 `return`，
两个话题都不发。串口节点仍有 750 ms 看门狗：运动中断流会自己补一帧 `06`，
所以不会一直往前冲。

验证：重启后画面里没有目标，`/status` 是：

```json
"serial":{"connected":false,"simulated":true,"seq":0,"frames":[]}
```

### 3. 串口页加清除和过滤

- 方向过滤：全部 / TX / RX；
- 命令位过滤：全部 / 01～06；
- 清除按钮：清空显示和本地缓存；
- 服务端 `/status` 增加 `seq`（累计帧数），客户端按 seq 增量追加，
  不再每 750 ms 整表重画，清除后旧帧也不会又冒出来；
- 客户端最多保留 300 行，方便往回滚。

验证：手工发两条命令后：

```json
"serial":{"seq":2,"frames":["TX [SIM] AA 55 01 88 FF 87",
                            "TX [SIM] AA 55 02 50 00 51"]}
```

### 4. 右侧滚动条

- 终端 `QPlainTextEdit` 的竖向滚动条从「永远隐藏」改成按需显示；
- 串口帧区本来就允许滚动，横向不换行。

```bash
# 看状态
curl -s http://127.0.0.1:18080/status
```
