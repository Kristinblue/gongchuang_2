# 最近目标与定向侧拨方案

2026-11-26。目标是尽快把一块合格物体单独套进方框。物块始终接地，终点是退开后通过单块复查。定向侧拨目前是设计，方向和行程要用仿真标定。

## 1. Search 只选一次

固定搜寻俯角，只看本帧可见、位于安全区外的物块。首件完整送入本方物资区前，只选绿色；之后从绿、黑、橙中共同选最近的一块。蓝块始终参与障碍判断。首件入区的判定由整场任务提供，现有的投放动作结束信号还不能证明完整入区。见[比赛规则](../../../RULES.md)。

在同一视角下，用检测框底边越靠下估计物块越近。底边接近时优先选周围没有旁块的，再选靠中线的。贴着画面底边的框可能被裁掉，不能靠一两个像素区分远近。选定后 Track 只负责认回并靠近这一块；短暂丢框先停车等新帧，连续丢失再重选。

## 2. 靠近后先判断能否直接套

低头、停车，在稳定的新画面上判断。先确认目标框完整且已对准，再看套下方框时会占到的范围。第一版可以用目标框向左右、前后留少量余量表示这个范围。余量用固定抓取俯角下的实际方框轮廓标定。

- **能直接套**：其他任何物块的检测框都不与套取范围相交，连续几帧判断一致，就直接套住目标。即使画面另一边还有一堆物块，也走这条路。
- **需要侧拨**：目标看得清，但有旁块的框伸进套取范围。此时才检查左、右两侧。
- **看不清**：目标或准备使用的那一侧被裁出画面、明显遮挡，先退一点重新观察。看不清的地方不能算空地。

## 3. 一次只向一侧拨

以车头视角为准。**向左拨**时，让闭合方框的左侧外缘对准目标的右边，慢慢前移到目标侧面，再让车向左小角度转动，用方框外侧把目标推向左方。向右拨时动作镜像。可以通过转动车头改变对准位置，底盘只需直行和转向。

左右各检查一次。先看方框能否到目标侧面，再看从目标当前位置到预计落点的扫过范围。这个范围需要看得全，避开其他物块的框、安全区和围栏。只留有落点、途中隔着蓝块时，这一边也算堵。两边都可用就选就位转角较小的一侧；两边都堵就换一个目标，本轮搜寻先跳过刚放弃的那块。

一次短拨后立即停车，等方框退出目标视野再重拍。用新框重新做第 2 步判断，能套就套，仍挤就换目标。拨后目标可能换跟踪 ID，应结合原目标类别和预计落点重新确认。若对应不清楚，回到搜寻。侧拨角度与靠近距离以“刚好让目标离开旁块”为标定目标。

## 4. 单块复查与验证

套住后后退一小段，低头用连续新帧检查爪口。只有一块且类别与目标一致，才交给转运；多块、错色或无法确认就释放并重新观察。

实现沿用 `GoTo` 选块和追踪、`Grabber` 判断与动作、`MyCMD` 发指令。先用客户端同一套相机参数测试四种摆法：

| 摆法 | 应该看到的结果 |
| --- | --- |
| 孤立绿块，远处有干扰 | 直接套取，侧拨次数为零 |
| 目标挨着旁块，仅左侧或仅右侧可用 | 分别验证两个方向；闭合方框从另一侧就位，短拨后目标与旁块分开 |
| 蓝块夹在目标与空地之间 | 放弃经过蓝块的方向，蓝块没有被带走 |
| 两侧都堵，附近另有合格目标 | 换目标，避免在同一堆反复尝试 |

每场保存选定时和动作后的俯视图，记录首次锁定到单块复查通过的耗时、侧拨次数、实际随车移动的物块。用俯视位姿核对结果，运行中的选块和侧拨只使用车载画面。
