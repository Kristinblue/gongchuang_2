# 先试夹再重夹

2026-11-26 晚。之前的闭爪侧拨在摆位里挪动了物块，最近间距没有拉开。本轮把它简化掉，保留已经测到能拉开邻块的开爪斜推。

- 接近目标后，允许目标偏一点或检测框贴底。正前方没有旁块直接挡住时，可以先合爪后退 7 cm。
- 后退低头后，连续看到一块同类目标但它偏侧或框不完整，就松爪，回到近处相机角度重新靠近。每次抓取最多重夹两次。
- 连续看到多块或错块，或者旁块一直堵住爪口，就开爪斜推。再次触发打散时换一侧。交付转运仍要求连续确认爪口只有一块位置合适的目标。

本地断言覆盖了偏侧尝试合爪、后退、连续帧触发重夹、两次重夹上限、正常单块通过，以及多块触发打散。

| 仿真摆位 | 结果 |
| --- | --- |
| 31，孤立绿块 | 首次合爪，后退后通过单块复查 |
| 32，绿块贴一块黑 | 先尝试夹偏心的绿块，后退复查看到多块，斜推后最近中心间距从 4.6 cm 增至 8.4 cm |
| 34，绿块夹在两块黑之间 | 首次尝试合爪后检测到多块，斜推后最近中心间距从 3.9 cm 增至 7.5 cm |
| 35，复查时绿块过分偏侧 | 开爪回搜寻，重新靠近抓取，单块复查通过 |
| 36，复查时绿块在爪口中间 | 直接通过单块复查 |
| 37，模拟第一次后退后只带住一部分 | 从偏侧复查画面开始，开爪、低头重新靠近、合爪后退，最后通过单块复查 |

32 和 34 都观察到了打散后的间距变化，测试窗口内没有完成下一次抓取复查。位移以物块中心距为准。
