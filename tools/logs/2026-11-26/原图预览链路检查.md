# 原图预览链路检查

仿真客户端原来从 `/video` 收带框 JPEG，安全区调试会用这张画过图的画面重算。现在仿真和香橙派客户端统一请求 `/safety/frame?format=jpeg`，每次收到一张未画框的 720p 图和对应检测框、锁定目标、参考点。图像与检测框按 ROS 时间戳配对，锁定目标也必须和图像同帧。客户端用原图算安全区掩膜，画框和画轮廓时使用副本。

抓取阶段的黄框已接上。任务阶段随响应传回，客户端放在画面上方。旧 `/video` 保留给兼容入口，无格式参数的 `/safety/frame` 仍支持 PNG。

Windows EXE 和 ROS 服务端编译通过。用仿真数据启动新版服务端并请求原图，两种格式都返回 1280×720，同帧坐标和状态可解析。4 次请求中，JPEG 大小中位数约 32 KB，耗时约 27 ms；PNG 约 379 KB，耗时约 111 ms。测量是在 Windows 与 WSL 的本机链路，实际压缩大小随场景变化。安全区检查使用这些未画框像素，线上显示用 JPEG 解码后的像素。
