# 修复仿真打散与 720p

2026-11-24

- 物理场地仍是单绿块测试版。确认当前 SDF 与完整备份唯一差异为删掉 19 个物块后，恢复了 20 块。单块副本位于 `build/gripper_manual-one-green.sdf`。
- 仿真打散复用原电脑版的 8 秒直推和正向增益 0.0016。计时读取 Gazebo 物理时间，追踪时恢复原小增益，实车参数沿用 YAML。客户端仿真预览覆盖为 1280×720。
- 实测从完整场地运行，车从启动前到切入搜寻移动 1.26 m，20 个物块都移动超过 1 cm。该结果验证打散动作确实移动了物块，未验所有物块均已分离。读取客户端使用的 HTTP MJPEG，JPEG 解码尺寸为 1280×720。原仿真车体用于验证，未测试 01 夹爪或抓放。

复测命令为 `python -X utf8 build/check-scatter-720p.py`，使用原仿真的 yolov8 Python 环境，单次位姿结果在 `build/scatter-720p-result.json`。
