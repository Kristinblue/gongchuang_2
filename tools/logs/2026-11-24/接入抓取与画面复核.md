# 接入抓取与画面复核

- GoTo 到位后进入抓取。复核同一类别和 ID 的新检测帧，开爪后保持相机俯角，沿目标慢速接近。物块底边中心连续进入合爪范围才停车发合爪指令。丢目标、框超出画面或限时内无法对准，停车回搜寻；断帧沿用原停车逻辑。
- `robot.yaml` 的 `task_node.grab` 可调合爪范围。当前用 720p 原图，底边在第 620–690 行，横向误差不超过 26 px。尚未实机标定范围或验证夹住。
- `colcon build --base-paths src --symlink-install --packages-select action_pkg robot_launch desktop_server_pkg --cmake-args -DCMAKE_BUILD_TYPE=Release` 编译通过；`build/check-grab-node.py` 用独立 ROS 域向 TaskNode 喂检测帧，验证到位、同目标确认、慢进、合爪、目标丢失、裁切、超时和断帧停车。当前客户端仿真仍在运行，测试没有中断它。
