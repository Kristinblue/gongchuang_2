## 用到的命令

在 Windows PowerShell 里用 `wsl -e bash -lc "..."` 进 WSL 执行，也可以先 `wsl` 进去再敲。

```bash
# 清空重编（本次用的；平时直接 bash tools/build.sh 即可）
cd /mnt/d/my_project/gongchuang_ros2
rm -rf build install
bash tools/build.sh

# 看某个包有哪些可执行文件
source /opt/ros/humble/setup.bash
source install/local_setup.bash
ros2 pkg executables vision_pkg

# 启动预览，不接相机也可以（端口换成 18099 避免和已有服务冲突）
bash tools/run.sh port:=18099

# 另开一个窗口验证：只有服务没有画面
python3 tools/verify_preview.py --url http://127.0.0.1:18099 --no-video

# 设置接口需要带客户端头
curl -H "X-Gongchuang-Client: smoke" -d "jpeg_quality=70" http://127.0.0.1:18099/settings
curl -H "X-Gongchuang-Client: smoke" -d "confidence=0.54" http://127.0.0.1:18099/settings  # 要带模型启动

# 带模型（WSL 用 ONNX）
bash tools/run.sh port:=18099 model:=models/train5.onnx
```
