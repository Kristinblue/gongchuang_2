# 2026-11-14 · 有线联调：STM32 指令驱动仿真车

时间：16:58–17:22

## 做了什么

1. `tools/sim/stream.py` 增加控制端口 8091：接收 `D 速度 转向`、`C 俯角`、`G 开合`，转给仿真后端。
2. `tools/stm32_sim.py` 增加 `--sim-host`：假板把算出来的速度和转向按 10Hz 转发给仿真，
   镜头和夹爪命令也一起转，等于让下位机指令直接驱动仿真车。
3. 有线客户端接本机仿真：客户端只会连 SSH 别名对应的派，所以从 Windows 开一条反向隧道，
   把派上的 18080 让给本机。派只当跳板，不跑新代码。

```text
客户端 --ssh -L--> 派 127.0.0.1:18080 --ssh -R--> Windows 127.0.0.1:18080 --> WSL ROS
```

## 验证

- 车真的动了：`/approach_test/start` 之后
  - 转向误差 `02`：100 → 89 → 74 → … → 7 → 0（居中）
  - 前进误差 `01`：-180 → -160 → -130 → -101（继续靠近）
  - 预览画面里物块从远处小方块变成近处满屏，说明闭环成立。
- 反向隧道：在派上执行 `curl 127.0.0.1:18080/status`，返回的是本机仿真的
  `{"camera_source":"http",...,"video_available":true,...}`。
- 客户端进程已启动（窗口「工创赛客户端」），模式要手动切到 `pio-wired` 再点「连接」。
